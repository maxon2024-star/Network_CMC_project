# Транспортный уровень распределенной системы телеметрии

Сервис транспортного уровня предназначен для приема сегментов телеметрии от агентного уровня, имитации сетевых потерь, буферизации и передачи агрегированных данных на прикладной уровень по протоколу Server-Sent Events (SSE).

## Требования к окружению

* Операционная система: Linux, Windows (с поддержкой WSL2) или macOS.

* Установленный **Docker** и **Docker Compose**.

* Наличие свободного порта `8001` для веб-сервиса и `8080` для панели мониторинга очереди.

## Структура проекта

```
transport-level/
├── app/
│   ├── __init__.py
│   ├── config.py
│   ├── kafka_worker.py
│   ├── main.py
│   └── models.py
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
└── .env

```

## Конфигурация (.env)

Создайте в корневой директории файл `.env` со следующими параметрами:

```
PORT=8001
KAFKA_BOOTSTRAP_SERVERS=kafka:29092
KAFKA_TOPIC=telemetry-segments
LOSS_PROBABILITY=0.02
AGGREGATION_INTERVAL_SEC=5
MAX_MISSING_CYCLES=3

```

## Инструкция по развертыванию

1. **Переход в директорию:**
   Откройте терминал и перейдите в папку с исходным кодом транспортного уровня.

2. **Сборка и запуск контейнеров:**
   Выполните команду оркестрации для сборки образов и запуска сервисов в фоновом режиме:

   ```
   docker compose up --build -d
   
   ```

3. **Проверка статуса работы:**
   Убедитесь, что все компоненты запущены и функционируют корректно:

   ```
   docker compose ps
   
   ```

## Управление сервисами

* **Остановка контейнеров:**

  ```
  docker compose down
  
  ```

* **Просмотр логов:**

  ```
  docker compose logs -f transport-service
  
  ```

## Проверка работоспособности

* **Веб-интерфейс Kafka UI:** Доступен по адресу `http://localhost:8080` для мониторинга топиков и сообщений в реальном времени.

* **Эндпоинт приема сегментов (`POST`):** `http://localhost:8001/api/v1/segments`

* **Потоковая передача данных (`GET` SSE):** `http://localhost:8001/api/v1/telemetry/stream`
